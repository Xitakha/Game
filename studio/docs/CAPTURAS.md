# Capturas de pruebas

Las capturas de las pruebas con Playwright (arte, jefes, aldea, balance, vista inclinada…) **no se guardan en el repo** porque pesaban ~200 MB.
Se regeneran con los scripts de `tools/` (por ejemplo `tools/card-swarm-boss-bot/caps_*.js`, `tools/card-swarm-iso/caps.js`).
Solo se versiona `capturas-movil/` (12 imágenes pequeñas de la versión móvil).
